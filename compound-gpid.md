# test-AIR-global-survey

## Objective

Create an application for testing the AI-readiness global survey, allowing users to complete the survey and provide feedback. The application will store that feedback.

## Key Deliverables

- Survey completion workflow
- User feedback collection
- Feedback storage

## Constraints

- It should use current draft survey questions exactly.
- It should only be available to pre-determined test users.
- It should store their responses precisely.

## Current Focus

Survey questions are set. Now we will build the testing application.
